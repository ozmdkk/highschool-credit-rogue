# 🎮 고교학점제 로그 (High School Credit PokéRogue)

중학생과 예비 고1을 위한 **2022 개정 교육과정 & 고교학점제 192학점 이수 체험형 턴제 웹 RPG 게임**입니다.

---

## 🌟 주요 특징
* **16:9 스마트폰 가로 화면(Mobile Landscape) & PC 반응형 UI**
* **2022 개정 교육과정 보통교과 편제표 100% 반영** (대수, 미적분Ⅰ, 미적분Ⅱ, 세계시민과 지리, 로봇과 공학세계 등)
* **4대 교과 속성 상성 시스템** (`🟦 수리·논리` > `🟩 자연·탐구` > `🟪 창의·융합` > `🟨 인문·사회` > `🟦 수리·논리`)
* **3개년 48 Wave 대장정**: 1~3학년 배틀(30회), 학교생활 딜레마 이벤트(15회), 학년말 보스전(3회)
* **2단계 최소성취수준 보장지도(그로기 40% 부활) & 과목 미이수(I등급) 게임 오버**
* **제로 디펜던시 (Zero Dependency)**: 별도 설치나 빌드 없이 `index.html` 더블클릭만으로 즉시 구동

---

## 🚀 실행 방법

### 1. 로컬에서 바로 실행하기
* `index.html` 파일을 크롬, 엣지, 사파리 등 웹 브라우저로 더블클릭하여 엽니다.

### 2. GitHub Pages로 스마트폰/웹 배포하기
1. 이 저장소를 GitHub에 업로드(Push)합니다.
2. GitHub 저장소의 **Settings** ➔ **Pages**로 이동합니다.
3. **Branch**를 `main` (또는 `master`) / `/root`로 설정하고 **Save**를 누릅니다.
4. 잠시 후 발급되는 `https://<username>.github.io/<repo-name>/` 링크를 스마트폰 브라우저나 어디서든 열면 바로 플레이할 수 있습니다!
